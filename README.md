# codex内置浏览器一键翻译

为 Codex / ChatGPT 内置浏览器准备的 Manifest V3 网页翻译扩展，当前版本 **1.2.1**。点击网页左下角按钮，将可读取的网页文本翻译成简体中文，也可恢复原文。

使用浏览器提供的本地翻译模型，无需 API 密钥。首次下载模型需要联网；模型就绪后，翻译文本在本机处理。此项目是独立开发的浏览器扩展，与 OpenAI 无隶属关系。

## 下载与安装

1. 从 [Releases](https://github.com/Austinlu29/codex-browser-one-click-translate/releases) 下载 `page-translator.zip`，解压到一个固定目录。
2. 在 Codex / ChatGPT 右侧内置浏览器手动进入 `chrome://extensions/`。如果提供开发者模式和“加载已解压的扩展程序”，开启开发者模式并选择解压后的目录。该目录应直接包含 `manifest.json`。
3. 刷新需要翻译的网页，点击网页左下角“一键翻译”。

加载入口是否可用取决于当前应用版本与功能配置。本项目不能保证所有 Codex / ChatGPT 版本都支持加载扩展。普通 Chromium 浏览器也需要提供 `Translator` API 才能运行本地翻译。

使用源码时，选择仓库中的 `page-translator` 目录。ZIP 中不包含模型，模型由浏览器自行下载和管理。

## 更新已安装的扩展

1. 在内置浏览器的扩展管理页面中，对“一键网页翻译”点击“重新加载”。压缩包用户先解压新版文件覆盖旧版。
2. **刷新需要翻译的网页**，让旧的 Google 版本脚本退出。
3. 点击网页左下角“一键翻译”。首次使用可能要下载本地模型，面板会显示进度；模型下载完成后，网页文本在本机处理，不请求 Google 翻译接口。

这是本地模式的独立版本：没有 Google 云端翻译回退，也不要求 API 密钥。模型由浏览器提供，首次模型下载本身可能需要联网。

## 修复“模型下载 100%”一直不结束

1.2.1 不再等待语言检测模型加载完成才开始翻译；检测未就绪时先参考网页声明的原文语言，默认英语。可以在扩展弹窗直接指定“英语”等原文语言。

下载完成后显示“正在初始化”，不再停留在“下载 100%”。初始化最多等待 30 秒，完整模型准备最多等待约 2 分钟；超时会显示原因并清除失败缓存，允许重新准备。模型准备期间主按钮显示“取消准备”，可主动中断等待。单次语言检测和翻译推理也有等待上限。

若已提示初始化超时，再次点击重试；仍失败时关闭并重新打开内置浏览器后测试。这类浏览器模型初始化故障无法靠进度文字保证修复，本版本提供超时、取消与重试路径。

## 使用

- 默认自动判断原文语言，翻译为简体中文。短文本识别不可靠时参考网页声明的语言，未声明时先使用英语。
- 原文判断不准确时，在扩展弹窗的“原文语言”中指定英语、日语、法语等，再点击网页按钮。
- 页面标题和屏幕内文字优先翻译，完成的文本立即显示；全页相同原文仅处理一次。
- 新增内容自动翻译，点击“恢复原文”可撤销替换。网站后来自己更新的内容不会被旧原文覆盖。
- 新遇到的语言需要尚未下载的模型时，会提示再次点击“一键翻译”准备该语言包。首次模型创建要求用户实际点击，弹窗中的翻译按钮不能保证满足网页的用户激活要求。
- 可收起左下角按钮或从扩展弹窗关闭悬浮按钮。

## 兼容性与数据

需要浏览器提供 `Translator` API；自动识别使用可用的 `LanguageDetector` API。两者在当前内置浏览器的普通页面中检测为可用，英译中模型实测成功。但这不保证所有网页策略或扩展运行环境都允许 API；插件会显示具体失败原因，不会静默回退到云端。

子页面通过扩展消息向主页面的本地模型请求翻译，避免每个 iframe 分别下载模型。译文和模型实例只在内存中缓存；扩展仅持久化按钮显示与原文语言偏好。扩展无翻译服务器访问权限，也没有网络翻译请求代码。

“全部文本”指可读取的 DOM 文本，包括按钮、提示和开放 Shadow DOM。不包含图片/Canvas 文字、PDF、浏览器设置页、关闭的 Shadow DOM 或尚未加载的内容。输入值、可编辑区域、代码、`translate="no"` 与 `notranslate` 区域不参与翻译，纯中文/数字/网址跳过。超过 30,000 字符的单个文本节点跳过。模型速度取决于本机性能及语言包是否准备好。

## 开发、验证与打包

安装 Node.js 和 pnpm 后运行：

```sh
pnpm install --frozen-lockfile
pnpm test
```

26 项行为检查通过。生成安装包需要 Python 3，仅使用标准库：

```sh
python scripts/package.py
```

输出为 `dist/page-translator.zip`。扩展本身无需 Node.js、Python 或构建过程。

普通页面实测：测试环境中的内置浏览器提供本地翻译与语言检测 API，`Hello world` → `你好世界`；新版源文件配合模拟扩展消息桥验证翻译流程。实际安装的扩展隔离环境仍需独立验证。详情见 [验证记录](VALIDATION.md)。

官方说明：[Translator API](https://developer.chrome.com/docs/ai/translator-api)、[Language Detector API](https://developer.chrome.com/docs/ai/language-detection)。
